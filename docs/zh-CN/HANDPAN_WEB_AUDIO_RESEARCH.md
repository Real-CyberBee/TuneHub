# 手碟发声与 Web Audio 实现调研

## 结论摘要

手碟音色不能只用“基音 + 几个泛音 + 一个整体 ADSR”来逼近。真实声场更适合看作多个衰减速度不同、略有失谐的结构模态；一次击奏会激发这些模态，击打力度和位置改变各模态的强弱。低音 Ding 还会激发手碟内部空气腔与琴壳的低频共鸣。持续播放时，先前未消失的共鸣会与新击奏叠加。

TuneHub 的普通音色使用 `OscillatorNode` 和音量包络。手碟专用路径现以圆顶包络的短促接触脉冲驱动平行 `BiquadFilterNode` 带通共振模态；少量噪声只作为激励纹理，不直接进入输出。每个模态按自己的 Q 值衰减，低音 Ding 还带有轻微的 85 Hz 空气腔共鸣近似。它能保留重叠余音并产生模态拍频，但各击奏各自创建滤波器，尚未实现持久共振器状态和音符间的真实能量耦合。

开源合成器页面适合验证“模态共振”这条建模路线，不是手碟真实录音的音色标杆。用户实际试听后认为它也明显不如 Malte Marten 的真实演奏；因此不应因结构更复杂就假定听感更真实。TuneHub 已做录音节奏与频段的初步对照，仍需同响度试听和更细的单音测量。

## 找到的 Web Audio 实现

### `ManicardiFrancesco/handpan`

- 项目：[GitHub 仓库](https://github.com/ManicardiFrancesco/handpan)
- DSP：[AudioWorklet 共振器](https://github.com/ManicardiFrancesco/handpan/blob/master/src/dsp/handpan-processor.js)
- 模态参数：[音色场和共振参数](https://github.com/ManicardiFrancesco/handpan/blob/master/src/model/instrument.js)

直接阅读了这两个源码文件。实现使用每个模态一个二阶共振器，跨击奏保留共振器状态；击奏通过两个级联的一阶滤波器形成柔性接触力脉冲，而不是直接把宽带白噪声当作主要音头。每个音区有接近 1:2:3 的三个主模态，并给主模态配上相差少量 Hz 的伴随模态以形成拍频；更高的非谐模态只在力度较大时加入。低音及其他音符还能弱激发一个 Helmholtz 空气腔模态和两个琴壳模态，频率相近的音区之间会发生对称共振耦合。代码也把击打位置映射为各主模态的能量分配。

源码中的参考模态衰减时间随音高调整；高频模态更短，低音更长。模型还包含短促、带通滤波的接触音，但它是点缀，并非持续噪声层。以上是该仓库的实现设计，不代表每一只真实手碟都具有完全相同的模态频率或衰减时间。

该仓库没有发现公开许可证文件，因此这里只总结通用建模思路，不复制其代码或参数表。

### `vasiliismirnov/sounds-of-mind`

- 项目：[GitHub 仓库](https://github.com/vasiliismirnov/sounds-of-mind)

这是另一条路线：用真实手碟音频样本配合 Tone.js `Sampler` 播放。样本法通常更容易保留真实琴体瞬态和音色，但旋律音高、击打力度、位置与音长超出样本覆盖时，需要设计分层、变调或合成补足。仓库未发现公开许可证文件，因此不复用其中的音频样本。

### 真实采样来源核查

- [Pianobook 的 Handpan 页面](https://www.pianobook.co.uk/packs/handpan/)描述的是单样本键盘乐器。作者说明原始 Freesound 素材实际是钢舌鼓单音击奏，不是完整手碟多音区录音；它不适合作为本项目的真实手碟音色库。
- 搜索到的其他完整手碟包主要是商业下载或订阅样本。当前没有确认到可直接嵌入 TuneHub、且许可清楚的完整多音区多力度手碟采样库。可用录音若只许可个人作曲使用，也不能自动推导为允许随网页应用分发。
- 若要显著缩小与 Malte 录音的差距，优先使用作者明确允许网页分发的手碟多力度采样，或录制并取得明确授权的单只真实手碟样本；再以模态模型补足未采样的力度、音长和共鸣。不要从 Malte 的商业录音提取样本。

## 对当前音色的诊断

早期实验把宽带噪声直接叠到音头，听起来偏硬、像钟。第一版模态音源虽把噪声限制为激励，但瞬态过尖；之后改成纯平滑接触脉冲，又把用户认可的拨弦感削弱了。本轮按用户反馈改为圆顶 `sin²` 包络的短拨弦脉冲，并让不同演奏技法使用不同脉冲时长；噪声只激发共振器，不直接进入输出。音源使用接近 1:2:3 的主模态、弱伴随模态，以及按模态衰减时间计算的 Q 值。低音腔体近似设为弱 85 Hz 模态，替代先前不合适的半频正弦低音。

新一轮小调整把触弦位置加入事件：外缘音相对提高高阶模态激发，低音 Ding 使用偏中心落点。同时把手碟内容包的卷积混响降到近距离空间量级，避免把房间尾音误当作琴体共鸣。这是宽泛物理启发式，不是由 Malte 录音反推的精确参数，需由用户试听判断是否改善。

针对用户反馈的“缺少金属轻灵感、最大速度和密度仍偏慢”，发现 UI/生成器原先把速度限制在 110 BPM、能量限制在 0.62，每小节只有两次固定脉冲，且没有十六分音符装饰。现已把范围扩到 132 BPM / 0.86，增加受密度控制的十六分邻音装饰，并让明暗参数实际改变高阶模态能量。默认速度与密度也相应上调。下面记录随后完成的录音对照与修正。

## Soulshine 录音实测（2026-09-25）

重新从 Malte Marten 官方视频 `TUeY4kUiLZ8` 下载音频，仅用于本机分析；未把录音或取样放入项目。测量使用此前转换的 22.05 kHz 单声道 PCM（331.18 秒），并用新下载文件核对来源。以 650 Hz 以上的短时能量上升估计击奏起点：25–55 秒约 2.4 次/秒，75–105 秒约 2.5 次/秒，200–230 秒约 3.0 次/秒；忙碌段落的相邻起点有约 0.1–0.2 秒的短连击，也有明显较长的空隙。检测会把某些泛音变化算作新击奏，因此这些数字是比较尺度，不是逐音转写。

同样方法下，修改前 TuneHub 默认生成约 2.9 次/秒。总击奏数并不特别低；听起来慢的主要原因更可能是轻音装饰分散且偏弱，两小节型几乎原样循环，以及缺少成组的快速动作。修改后把十六分装饰组成短连击，取消逐音随机删减，以整拍换气和句尾留白保留动机的呼吸。最高密度、132 BPM 时，固定种子的前 30 秒有 129 个旋律事件；这是生成事件数，不等同于听到的清晰击奏数。

频谱比较显示，修改前 TuneHub 的 350–1500 Hz 能量相对 80–350 Hz 偏强。曾据此降低音列、缩短高阶模态，并减少房间混响；用户试听认为更不像真实手碟，尤其失去了空灵余音。由于两者调音、麦克风与母带处理不同，频段比值不能直接反推出合成参数。这组改动已撤回，固定音列仍为 D3 Ding 的 D 大调五声音列。

进一步用浏览器离线渲染一颗 D4 手碟音，发现干声在约 0.5 秒后直接变为零。原因是约 6 毫秒的激励缓冲结束后，浏览器提前停止了共振滤波链的处理。现让一条循环的静音源在模态衰减期间保持滤波链运行，并适度延长基音、第二模态与低音 Ding 的衰减。相同单音在 0.8 秒处的干声 RMS 从约 `4.5×10⁻⁵` 升至 `2.6×10⁻⁴`，尾音来自琴体模态；房间混响保持克制。这个检查验证了技术原因，音色仍需实际试听。

当前合成器仍缺真实琴体的跨音区耦合和录音中的微小音色差异；频谱校准也无法代替用户在同一耳机、同一响度下试听。本轮没有使用 Malte 的录音样本作为音源。

## 真实单音对照：FreePats Hang（2026-09-25）

参照为 [FreePats 的 D 小调 Hang 音色库](https://freepats.zenvoid.org/ChromaticPercussion/hang.html)，其 [README 与单音文件](https://github.com/freepats/hang-D-minor)标明：2017 年在马德里 Medialab-Prado 礼堂录制，使用 Zoom H1，原始录音经过裁切、编辑和处理；发布许可为 CC0。它是真实钢制 Hang 的单音录音，并非 Malte Marten 所用乐器，也不是未经处理的消声室测量。项目目前只在本机下载参照文件分析，没有把样本加入 TuneHub 音源。

选取双方共有的 A3（MIDI 57）和 E4（MIDI 64），各自对齐起音后，把 50–150 毫秒的响度作为 0 dB，比较 50 毫秒窗口的整体衰减。频带能量取起音后 70–270 毫秒。真实录音分别取 5 次 A3、6 次 E4 击奏的中位数；TuneHub 用默认明暗、0.7 力度和相同音高离线渲染单击。

| 音高 | 0.8 秒：真实录音 | 0.8 秒：TuneHub | 真实 2× 基音频带中位数 | TuneHub 2× 基音频带 |
| --- | ---: | ---: | ---: | ---: |
| A3 | −13.7 dB | −33.1 dB | −23.6 dB | −6.8 dB |
| E4 | −18.9 dB | −35.3 dB | −10.2 dB | −5.1 dB |

由此可见，目前合成单音的可听尾音仍明显过快衰减；A3 的 2×、3× 基音频带又相对基音过强。真实 A3 还带有约 294 Hz 的邻音线谱和约 90 Hz 的低频成分；README 明确说明该 Hang 的其他音区会被一次击奏带动。90 Hz 成分可能同时受琴体、空气腔和礼堂影响，不能单凭这份录音归因。不同场音与不同击奏之间的模态比例变化很大，说明一套固定比例的合成参数难以覆盖整只琴。

这个对照明确了后续引擎改进方向：区分场音的模态比例，保留更久的真实琴体余振，并加入受控的跨音区弱共鸣。由于参照琴为 D 小调、TuneHub 当前示例琴为 D 大调，不能直接把其样本变调后混入当前内容包；FreePats 也明确提示变调会把固定的背景共鸣一起移走。

### 本轮单音校准

仅修改手碟合成路径。将场音的激励从数毫秒纯随机噪声改为约 1 毫秒的圆顶单向接触脉冲，叠加少量确定性表面纹理。纯随机激励曾使 D4 的基音偶然减弱，导致不同音高的泛音比例剧烈变化。场音基音按音区设定较长的模态衰减，二、三倍频按音区分别配比；A3、D4、E4 增加低电平的琴体邻音耦合。空间混响参数未增加，固定 D 大调音列与 UI 未改变。

相同渲染、起音对齐和分析方法下，更新后的结果如下。数值为相对起音响度或相对基音频带的 dB；真实录音一列是多次击奏的中位数。

| 音高 | 0.8 秒：真实 / 更新后 | 二倍频：真实 / 更新后 | 三倍频：真实 / 更新后 |
| --- | ---: | ---: | ---: |
| A3 | −13.7 / 约 −14.0 | −23.6 / 约 −23.3 | −32.8 / 约 −33.2 |
| D4 | −19.0 / 约 −16.5 | −14.6 / 约 −12.2 | −10.7 / 约 −13.8 |
| E4 | −18.9 / 约 −18.3 | −10.2 / 约 −10.1 | −12.6 / 约 −12.5 |

这些指标说明尾音长度和前三个主模态已有明显改进，**不代表听感已与真实 Hang 相同**。尤其 1.5–5 kHz 早期频带仍偏弱：A3 约 −52 dB，对照约 −43 dB；E4 约 −49 dB，对照约 −36 dB。高阶模态已适度增强，但继续单纯增加高频会重现用户此前指出的钟声感。样本琴的调音、礼堂与处理和 TuneHub 示例琴不同，其他未取得真实单音的音区仍属近似。合成器也还没有琴体跨次击奏的持久状态。

### 高频圆板近似试验与回退

曾尝试用固支圆板特征根、击打位置和手指接触面积生成高阶音区模态，代替固定的几根高频模态。离线单音在 1.5–5 kHz、起音后 70–270 毫秒的相对能量，A3 由约 −52 dB 变为约 −41 dB（真实中位数约 −43 dB），E4 由约 −49 dB 变为约 −40 dB（真实约 −36 dB）。但 15–80 毫秒的 A3 高频比参考强约 10 dB，用户试听也认为更不像真实手碟。**该试验已从实际发音路径撤回**；频带能量更接近并不等于起音结构或音色更接近。

当前模型仍是经录音校准的模态近似，不是完整的手碟物理引擎。下一阶段需要研究起音阶段的能量传递和持续的琴体、空气腔耦合；录音用于分析与验证，不作为发声音源。

### 起音起伏对照（2026-09-25）

根据用户指出的“真实音在一开始有起伏”，把真实 Hang 的 5 次 A3、6 次 E4 单音与合成单音对齐起音，观察前 300 毫秒的全频、基音附近与 1.2–5 kHz 包络。每条曲线以 50–120 毫秒平均能量归一化，采用 2 毫秒 RMS 帧和 10 毫秒平滑；比较图保存在 `/tmp/handpan-attack-envelope.png`。这个结果来自 FreePats 录音，不应直接当作 Malte 演奏中每颗音的规律。

- A3：真实全频能量约在 60–70 毫秒达到首个宽峰，先前版本的合成 A3 也在相近时刻达到宽峰；因此不能简单给所有场音添加“慢起音”。
- E4：真实基音附近约在 10–15 毫秒出现明显峰值，之后 40、100 毫秒左右还有小幅波动；合成 E4 的早期基音峰值约在 55 毫秒，起音中间的变化也更平。真实高频在前 10 毫秒相对 50–120 毫秒平台明显更强。
- 将混响量设为零，E4 的起音偏平问题仍存在。绕过通用压缩/限制链后，合成 E4 的早期基音峰值提前到约 24 毫秒；但 A3 在前 20 毫秒出现过强峰值，与真实 A3 更远。因此没有将绕过动态处理作为全局修复。

这些观察支持“起音的能量传递与早期模态干涉是重要音色差异”这一假设，但还不能唯一归因于琴体耦合：录音中的麦克风位置、房间和后期处理也影响起音。随后加入 HaganeNote 制作者采样与其他辅助来源复核，发现两组来源明确的实物琴的 D4/E4 基音起音均比 TuneHub 快，而 A3 的首峰时间在不同琴之间明显冲突；细节见[跨来源比较](HANDPAN_SAMPLE_COMPARISON.md)。更稳妥的实现路径是让音区模态、琴壳与空气腔共享持续状态，按接触位置和激励力分配初始能量，再观察自然形成的局部起伏，而不是给输出加固定的音量颤动。

## 适合 TuneHub 的下一步

若继续走物理模型路线，应将每音各自的共振滤波器升级为 AudioWorklet 中持续运行的二阶模态状态，加入击打位置对模态的能量分配，以及相近音区之间的弱耦合。当前 Web Audio 节点版是可复现的轻量原型，尚未验证主观音色是否足够接近真实手碟。

若目标是更接近特定实物的音色，获授权的多力度、多击打位置手碟样本会是更直接的参照；物理模型和样本可以混合，但不应靠单纯增加全局混响来代替琴体共鸣。

### 同音异击与乐句呼吸（2026-09-25）

跨来源录音表明，即使同音、同琴的击奏也不会完全重合。内容包现在为每个两小节乐句生成一个稳定的手型倾向，再让左右手交替、每次落点和接触时长出现小幅变化；这些值随事件保存，实时播放与离线导出共用。发音引擎让接触时长改变激励脉冲的频谱，落点改变各模态受到的激发，保留原有的音高、琴体模态与尾音。

编排上，乐句内部沿一个可变峰点渐强再回落，段落依次由引音、主题、回环、展开走向余响。力度、少量留白与音色明暗沿这条弧线缓慢变化；随机数只决定局部手感和变化位置，同一种子仍能复现。这里没有把录音中的某一条起音曲线复制成固定包络。

### 旋律的短期记忆与动态动机

固定音列内的两小节动机现在按种子生成，不再从三条预写轮廓中挑选。新动机由带方向惯性的音级游走形成，句尾向合适的低中音区收束；相邻乐句可沿用并局部改写上一动机，也可开启新动机，段落切换时会调整音区。实际落音还经过轻量的加权转移选择：依据最近三颗音优先走邻音、避免无限重复，并在连续同向或大幅下跳后倾向转向与回升。曾加入固定的三次高音反复再急落低音手势，用户试听认为它打断了连贯性，现已移除；快速填音仍由原有节奏型和上下文选音自然产生。全部选择由独立的种子子流决定，可复现，也不会因触感随机数消耗而改变旋律选择。
