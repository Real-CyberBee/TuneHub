## 与 TuneHub 当前问题相关的观察和推断

以下是编曲/听感分析，不是官网直接陈述的专有技巧，也不应视作对某一首曲子的逐音转录：

- **连续感先来自动作与动机的连续，不来自音符数量。**若每个节拍独立抽取音高，或密度一增就增加随机敲击，听感会变成“音符很多但句子断裂”。需要让短动机跨小节可辨认，以节奏型或邻接音重复维持记忆点，再用少量替换、延音、休止、装饰发展它。
- **“随意但有规律”应由分层概率控制。**一个稳定但不机械的低音/重拍骨架承担方向感；上声部使用成组的交替手型和细分变化；每个两到四小节的小句只在少数位置偏移或填充。变化应围绕可感知的循环产生，而不是全局均匀撒随机数。
- **手碟是音区互相共鸣的单一声源。**低音 Ding 不宜只是偶尔插入的另一颗低音音符。它更像短句的锚点：在乐句起点、回归点或和声停留处用适度力度落下，再给金属基音和泛音真实的衰减时间；高音击奏要留出不遮蔽其共鸣的空隙。避免低音每拍重复造成机械鼓机感。
- **节奏表达依赖力度与时值层级。**主音、轻触音、边缘音应有明显力度/音色差别；强拍不必永远更响，但要有稳定的身体脉冲。微小的提前/滞后、切分和偶发的停顿能提供松弛感，不过随机 timing 偏差必须小且按手型/分句控制，否则会像失误。
- **速度和密度上限不等于风格。**调高 BPM 只会压缩间隔；调高密度只会堆叠事件。两项控制最好作用于 pattern 的步进/填充概率，同时保留低音锚点、句尾呼吸与留白，不改变动机的身份。
- **音阶不是核心的唯一解释。**Malte 发布的演出使用不同调音和作品语境；仅选 D Kurd 或相似音阶不能获得其连贯感。TuneHub 生成前应把音阶当作可用音集合，旋律仍由动机、音区、重心、乐句弧线和演奏手型决定。

## 可转化为生成器的设计建议

1. 生成一组短的 1–2 小节“主手型”，让相邻音大多落在邻近音区；低音 Ding、中心音与高音场音分配到不同角色。
2. 先安排 4/4 或 6/8 中明确可感的 pulse / subdivision，再用有偏好的 pattern 变体。每 2–4 小节发展一处，句末减少击奏或延长共鸣。
3. 将随机性放在变体选择：轻微移位、提前/延后一次重音、插入装饰、删去末尾一击、动机转位；固定周期回归基型。保留可复现的 seed 便于比较。
4. 让“击奏密度”调节细分填充率，“脉动速度”改变 pattern 的时长；两者都不应破坏底层节律和动机连贯性。
5. 若当前手碟音源只是正弦/泛音加卷积混响，需单独确认低音 Ding 的衰减包络、非谐泛音与音箱/浏览器真实播放效果。不能仅拉长全局混响替代低音琴体共鸣。

## 资料边界

本页只记录可公开访问的一手资料及高层设计启发。官网的自述说明的是创作理念，不证明每首作品都采用相同节奏结构；节奏分析是可检验的听感假设。对照实现前，应由开发者直接播放上面官方样本（建议 Soulshine 与 The Alps 各听一段、再听长场演出的不同时间点），确认脉冲、动机回归、休止及低音共鸣是否与这里的假设相符。
