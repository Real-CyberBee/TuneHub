# TuneHub 音乐内容术语

本文说明 TuneHub 对律制、音阶、框架、节奏、声部、乐器、音色和风格预设的用语。这些术语描述不同音乐问题，不要求对应彼此独立的代码接口。

## 术语

**律制**：描述音高如何映射为频率的体系，例如等分、比例或实测调音。

**音阶**：从某种音高体系中选出的可用音高集合。

**框架**：描述音高如何用于旋律和乐句的音乐规则，例如上行、下行、重点音和特征乐句。

**节奏**：描述声音在时间中的组织方式，例如拍点、循环和重音。

**声部**：编曲中的一条音乐线或角色，例如低音、旋律或打击乐。

**乐器**：一个可演奏的对象，包含或关联其演奏能力与发声实现；声部可以分配给乐器。避免把乐器等同于声部或音色。

**音色**：乐器或声音实现所使用的音质选择或配方；一件乐器可有多种音色。避免把音色配方当作完整乐器定义。

**风格预设**：供用户选择的组合方案，可绑定默认速度、生成代码、声部与乐器分配、音色及其他参数。框架、节奏、装饰和奏法可能互相耦合，生成代码可以将它们放在一起实现。不要把风格预设视为所有音乐规则的唯一容器，也不要要求相关概念必须拆成彼此独立的扩展接口。
