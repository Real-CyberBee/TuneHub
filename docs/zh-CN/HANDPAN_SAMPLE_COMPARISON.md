# 真实手碟单音的跨来源比较

## 研究问题

判断起音阶段是否存在跨乐器、跨击打都稳定的声学特征，避免用一只琴或一次录音的偶然细节修改 TuneHub 引擎。录音只用于分析与验证，不作为发声音源。

## 纳入规则

1. 来源明确说明是钢制手碟或 Hang 的真实击奏；钢舌鼓、合成音、演奏循环和变调复制的“多音区样本”不作为独立实物证据。
2. 记录制造者或乐器、录音环境、格式、许可、是否经过编辑，以及一次文件里是否仅有一次击打。
3. 优先比较同一乐器的多次击打，再比较不同乐器；不把多个文件直接混成一个平均值。
4. 起音按短时 RMS 超过本文件峰值约 4.5% 的时刻对齐；基音附近用三阶带通滤波，2 毫秒 RMS 帧与 10 毫秒平滑。比较首个宽峰时间、前 10–30 毫秒相对 50–120 毫秒的响度，以及高频随时间的变化。录音裁切与处理会影响这些值，因此只做同方法对照。

## 已确认：FreePats D 小调 Hang

[FreePats 原始页面](https://freepats.zenvoid.org/ChromaticPercussion/hang.html)和[录音仓库](https://github.com/freepats/hang-D-minor)说明这是一只真实 Hang，2017 年以 Zoom H1 在礼堂录制，文件有裁切和后期编辑，许可 CC0。现有本地单音共 A3 五次、D4 七次、E4 六次。

| 音区 | 次数 | 基音首个宽峰时间范围 | 早期起音相对 50–120 ms 平台 |
| --- | ---: | ---: | ---: |
| A3 | 5 | 50–76 ms | −2.3 至 −0.4 dB |
| D4 | 7 | 12–22 ms | +0.7 至 +4.0 dB |
| E4 | 6 | 10–50 ms，分布不集中 | +0.1 至 +3.8 dB |

同一只琴内也不存在统一的“先慢慢鼓起”起音：A3 一贯较晚，D4 一贯较早，E4 在不同击打之间明显变化。TuneHub 当前 A3 与这个来源的慢起音相近，D4/E4 的早期基音出现得偏晚。上述现象仍可能受音区形状、击打位置、麦克风、房间和后期共同影响。

## 跨来源复核（2026-09-25）

在 FreePats 之外，加入 [HaganeNote 制作者的实物采样](https://www.haganenote.com/vst/handpan-virtual-instrument.html)（每音一次）和 [GAMEDRIX974 单音包](https://freesound.org/people/GAMEDRIX974/packs/33041/)（每音一次）。后者未交代实物和录音过程，不能作为已证实的真实手碟。两组目前取得的都是 MP3 解码文件，只用于粗略的起音包络对照。相同方法渲染的 TuneHub 单音也列在表中；图见[跨来源起音比较](images/handpan-cross-source-attack.png)。

| 来源 | A3 基音首峰 | D4 基音首峰 | E4 基音首峰 | 证据级别 |
| --- | ---: | ---: | ---: | --- |
| FreePats，同琴重复击奏范围 | 50–76 ms | 12–22 ms | 10–50 ms | 确认实体 Hang，WAV；有录音和处理说明 |
| HaganeNote | 10 ms | 20 ms | 20 ms | 制作者声明为自制实物琴采样；MP3，每音一次 |
| GAMEDRIX974 | 18 ms | 12 ms | 26 ms | 实物身份未核实；MP3 预览，每音一次 |
| TuneHub 当前单音 | 86 ms | 84 ms | 56 ms | 算法合成；同音高、相同测量方法 |

前 10–30 ms 的基音能量相对 50–120 ms 平台，FreePats 的 D4 中位数为 +2.3 dB、E4 为 +0.85 dB；HaganeNote 分别为 +1.6、+2.8 dB。TuneHub 的 D4/E4 均为 −1.3 dB。两组来源明确的真实琴因此共同提示：**中高音区的基音起音比当前合成快，且会先有较强能量再回落或波动**。这只是有限样本上的方向，不是所有手碟、所有击打的固定毫秒值。

HaganeNote 提供了实体琴采样的来源说明，但其 32 个音高可能经过变调扩展，页面没有逐音击奏记录；因此它对 D4/E4 起音的支持仍是辅助证据，不能当成另一组多次原声击奏。

A3 则是反例：FreePats 五次都在 50–76 ms 才出现宽峰，HaganeNote 的单次 A3 在约 10 ms 已达峰。可能涉及琴体、击打位置、样本裁切和处理，不能据此给所有音加同一条“先鼓起”的包络。GAMEDRIX 的 A3 约 18 ms，也说明单一来源的 A3 不可当作普遍规律，但其实物身份未核实，权重更低。

为了把整体起音斜率与局部起伏分开，先以约 54 ms 平滑趋势扣除，再计算起音后 10–120 ms 基音包络的残差标准差。FreePats 的 A3/D4/E4 中位数依次为 0.39/0.44/0.58 dB；HaganeNote 为 0.91/0.63/0.52 dB；TuneHub 为 0.32/0.28/0.33 dB。合成起音可能偏平，但差异很小，MP3 编码、麦克风和录音处理都可能造成波动，不能把这些值直接做成固定颤音深度。

[GeorgeNaimeh 的 Shaktipan C# 录音](https://freesound.org/people/GeorgeNaimeh/sounds/493864/)是另一只来源说明较完整的实体琴。公开 MP3 预览从起点就有击奏，后续连续出现新击奏；只取最初约 100 ms 作辅助观察，估计第一击约 C#3，基音首峰约 26 ms。这里没有同音重复击奏，且首击的剪辑边界、编码延迟和后续重叠限制了精度，因此不把它并入上表的孤立单音统计。

### 频谱结构的交叉检查

在起音后 80–480 ms 的窗内，对 A3、D4、E4 做加窗频谱，FreePats、HaganeNote 和 TuneHub 都能在基音约 1、2、3 倍频附近找到峰。这说明目前合成器已有基本的音高结构，**仅把频率调到 1:2:3 并不能解决音色差距**。峰的相对强度却很不稳定：例如 A3 的 2 倍频峰相对基音，FreePats 一条击奏约 −32 dB，而 HaganeNote 约 +12 dB；录音、琴体、激励和可能的变调都会影响该数值。这种短窗频谱也无法单独证明各峰是独立振动模态，不能把某一组幅度直接写成通用参数。下一轮应比较同琴不同击打位置下各频带的**随时间交换与衰减**，而不只比一张平均频谱。

## 候选来源的使用边界

- [spen/Handpan](https://github.com/spen/Handpan)仓库提供 F2/F3/F4 音频，但 README 未说明录音者、具体乐器或样本来源；在核实前不能当作独立的真实手碟证据。
- 某手碟制作者网页的 A3 试听文件约 1.3 秒、16 kHz MP3，可用于粗看低频起音，不能用于尾音和金属高频的定量比较。其 D4 本地下载文件解码后为空，不纳入分析。详细来源与许可核验见 [样本来源清单](HANDPAN_SAMPLE_SOURCES.md)。

## 余振复核（2026-09-25）

此前只比较了约 0.8 秒的**总响度**。这会让低频基音掩盖二、三倍频消失的问题。现在以起音后约 0.12 秒为参照，对 1×、2×、3× 基频附近分别做带通 RMS 测量。下表为 0.8 秒时相对各自早期的下降量，单位 dB；FreePats 取同音重复击奏的中位数。比较绝对音量之前，先看每个频带自身衰减，避免麦克风增益的影响。

| 音高 | FreePats 2× / 3× | HaganeNote 2× / 3× | 旧合成 2× / 3× | 调整后合成 2× / 3× |
| --- | ---: | ---: | ---: | ---: |
| A3 | −8.9 / −10.4 | −16.1 / −13.3 | −36.1 / −35.9 | −17.6 / −16.4 |
| D4 | −6.5 / −16.7 | −25.6 / −18.2 | −43.0 / −43.5 | −17.6 / −16.5 |
| E4 | −15.8 / −13.1 | −17.0 / −20.5 | −34.3 / −35.3 | −17.5 / −16.4 |

旧合成的基音在 A3、D4、E4 上分别下降约 13、14、15 dB，接近部分真实录音；但二、三倍频通常下降 34–44 dB。因此听到的是逐渐只剩正弦基音的短促余音，而非持续变化的金属琴体共鸣。旧场音的二、三倍频 T60 分别只有约 0.96、0.55 秒。引擎还把所有共振滤波器的 Q 封顶为 500：即使延长 T60，D4/E4 的高阶模态仍会被这个上限截短。现按每个模态的衰减时间换算 Q，并把上限提高到正常音区用不到的 4000；同时降低上部模态的初始激励，使起音不会因此变成尖亮的钟声。调整后的表格是浏览器 `OfflineAudioContext` 直接渲染单音所得，未叠加房间混响。

项目的 D3 Ding 在 FreePats 样本列表里不存在，不能假称其已有同音对照。补充取 HaganeNote 的 D3 和 GAMEDRIX974 的 D3 公开 MP3 预览；两者的 2× / 3× 频带在 0.8 秒分别下降约 **−31 / −17 dB** 与 **−11 / −4 dB**。旧合成的 D3 是 **−35 / −64 dB**，第三模态尤其短；调整后约为 **−19 / −14 dB**，落在这两份参照之间。旧 D3 的 9 毫秒接触脉冲也显著抑制了倍频激励；改为 3 毫秒圆顶脉冲后，早期 2× / 3× 相对基音约为 −5 / −17 dB，更接近可观察到的实体琴低音结构。

这些录音有不同的琴体、空间和后期；FreePats 还在礼堂录制，HaganeNote 与 GAMEDRIX 的 D3 是 MP3 且每音仅一击。表中数值支持“旧合成高阶模态过快消失”这个方向，不证明某个固定 T60 适用于所有手碟。整曲里连续击奏、压缩器和琴壳模态之间的能量交换仍可能影响主观余振，需继续靠实际听感判断。

## 暂时可下的结论

用户指出的起音起伏值得研究。FreePats 的重复击奏与 HaganeNote 的单次制作者采样都显示 D4/E4 的基音起音比 TuneHub 当前单音更快，但 A3 的首峰时间在两只琴间明显冲突。频率约 1:2:3 的峰是跨来源共同结构，峰强和起音形状却不是统一常数。当前证据适合指导激励与模态能量传递的建模方向，不足以确定跨音区统一的包络或逐音修正值。下一步应获取更多**未变调、不同力度和击打位置、保留干声的同琴重复单音**，再对模态比例、早期能量交换和琴壳/空气腔余振分别做验证。
