# TuneHub · 音枢

[English](../../README.md)

TuneHub 是一款开源的浏览器音乐创作工作室。你可以通过聆听和尝试音乐想法来创作氛围音乐，不需要懂乐理。

![TuneHub 界面](../../docs/screenshot.png)

## 打开 TuneHub

在项目目录下运行：

```bash
python3 serve.py
```

然后在浏览器中打开 <http://127.0.0.1:8765/>。项目需要通过本地服务器加载 JavaScript 模块，无需安装依赖或构建。

<summary>一段告白</summary>

这个项目一开始只是源于自己的一时兴起。我是一名软件工程师，从小到大一直喜欢听纯音乐，从班得瑞到神秘园，从坂本龙一到阿鲲，从FKJ到汉斯·季默，从Audiomachine到David Garrett.....这些音乐助我思考，伴我入眠，然而我是一个乐盲，虽然尝试过学习，但效果并不理想。音乐生成大模型让普通人有机会创作歌曲，然而我却感觉不尽人意，因为我想的并不只是听到想听的音乐，还想享受创作音乐的过程（玩音乐）。

我实际在构造一款塔防游戏，塔每打一下就会生成一个音符。然而发现当几十个塔在同时打击，声音将杂乱无章。于是我问AI是否能够将这些杂乱的音符通过算法变为音乐。经过一段工作，输出很多我看不懂的乐理名词，还有一个演示的demo。我打开这个html，发现随机的音乐竟真的能变成音乐。我迫不及待分享它给我的朋友，并得到了赞同。我似乎找到了能够让不太懂音乐的人也能参与到创作音乐的方法，一个项目的原型在我头脑逐渐浮现。当然，生成音乐在很久之前就有了，但是在AI的帮助下，可能会让这个方法的真正落地成为现实——不但是不懂乐理的软件工程师能参与，懂乐理的行家也能参与。

我听纯音乐有15年了，涉猎了非常多类型的纯音乐，我知道现有的音乐随机生成器还远远不够释放所有潜力。

最后我想说的是《放牛班的春天》这部电影，我从中看到了乐音能让大家共鸣，减少人和人之间的隔阂，治愈人心。我们现在的世界有太多争端，存在很多相互猜疑和掠夺，希望这个项目能促进创造和分享。
